# 四个平台的字段映射

一条视频发到小红书 / 抖音 / B站 / 微信视频号 时，**同一个语义在每个平台叫法不同、字段位置不同、限制也不同**。这份表是把它们对齐的唯一依据。

所有内容均为真实创作者后台实测得出（2026-09 起）。

## 内容声明：四个字段，四个值（2026-09-29 起的默认）

**Jack 的默认是一律「无需标注」/ 不选。** 但四个平台这个字段叫法不同、可选值也不同，**别拿一个平台的值去套另一个**：

| 平台 | 字段叫法 | 选哪个 | 控件验收（必须是值，不是占位符） |
|---|---|---|---|
| 小红书 | 内容类型声明 | **不选**（选项里没有"无需声明"） | `.d-select` 仍是「添加内容类型声明」= 留空 ✅ |
| 抖音 | 自主声明 | 「**无需添加自主声明**」 | `.selectBox-buZRzi` 文本 = 无需添加自主声明 |
| B站 | 创作声明 | 「**内容无需标注**」 | `input.bcc-select-input-inner` 的 **value** |
| 视频号 | 视频标注 | 「**无需标注**」 | 按钮文本从占位符「选择视频标注」变成「无需标注」 |

⚠️ **B站 陷阱**：它可能把「内容为自制」显示在输入框里、同时组件状态是「内容无需标注」——oil-oil 文档要求**两个观察都要**。本流程按 Jack 偏好**不开原创/自制声明**。

⚠️ **视频号的视频标注存不进草稿**（见 `gotchas.md` 第六条），**必须最后设、设完不再保存**。

## 小红书

### 标题字数：加权算法（不是简单字符数）

```
ASCII 字符（含英文字母、数字、空格、半角标点）  每个算 0.5
其他 Unicode 字符（含中文、全角标点）          每个算 1
上限 20，加总后【向上取整】                   ← ceil 不能省
```

**例**：`Agent接入达芬奇，剪辑全自动`
→ ASCII `Agent` = 5 × 0.5 = 2.5；中文 `接入达芬奇，剪辑全自动` = 11
→ 加权 13.5 → **发布页显示 14** ✅

⚠️ **两个坑**：① 漏掉 ceil 会算少（`Agent` 加权 2.5，页面显示 3）；② 半角标点也按 0.5 算，不是只有半角空格。

**未超限时必须保留原标题，不要自作聪明截断。**

完整权重表、实测样例与配套计数工具见 [`title-limits.md`](title-limits.md) 与 [`../tools/title-counter.html`](../tools/title-counter.html)。

### AI 声明（内容类型声明）

下拉四项，**选项文本即最终写法**：

```
虚构演绎，仅供娱乐
笔记含AI合成内容        ← AI 生成内容选这个
内容包含营销广告
内容来源声明
```

⚠️ **四个选项里【没有】"无需声明"这一项**（2026-09-29 实测）。

而 Jack 的默认是**一律无需标注**，所以：

- **留空**（控件停在占位符「添加内容类型声明」）= "无需声明"的正确表达 ✅
- **如果发布时它拦住不让发**：四个选项都在声明一件对内容不成立的事，**停下来问 Jack**，不要自己挑一个。真要挑，最中性的是「内容来源声明」（唯一不带 AI / 营销 / 虚构判断的），但**仍然是个不准确的声明**。

### 话题：必须落成真实实体

编辑器是 tiptap。**话题实体在 DOM 里长这样**：

```html
<a class="tiptap-topic" data-topic='{"id":"...","link":"xhsdiscover://topic/v2/...","name":"DeepSeek"}'>
```

编辑器文本里会出现 `[话题]` 标记：`#DeepSeek[话题]#`

**纯文本 `#xxx` 不算实体，会被平台忽略。**

### 封面

- **默认 3:4 竖屏**（除非明确要求横版）
- 编辑器入口是 **hover-only** 的 `.cover-edit-entry`，见 `selectors.md`
- 验收靠 `ros-preview.xhscdn.com` 的 URL

## 抖音

### 字段

- **作品描述**（= 标题，≤30）
- **作品简介**（编辑器，≤1000，本流程默认不写）
- 话题用 `#添加话题` 按钮

### AI 声明（自主声明）

**是个弹窗**，不是下拉：

```
内容由AI生成              ← 选这个
内容为个人观点或见解
内容为转载信息
内容含营销推广信息
虚构演绎，仅供娱乐
无需添加自主声明
```

点选项 radio → 再点弹窗里的「确定」。

### 话题实体

```html
<span data-mention="#">#达芬奇</span>
```

**判定依据：`[data-mention="#"]` 节点才算选中话题**，编辑器文本里的 `#达芬奇` 只是残留。

### 封面：**必须两个槽都给**

- 横封面 4:3
- 竖封面 3:4

**只给一个是"横/竖双封面缺失"，平台会警告。**

## B站

### 字段

- **稿件标题**（≤80）
- **简介**：Quill 编辑器（**本流程默认不写**）
- **分区**：下拉选择（如「人工智能」「科技数码」）
- **标签**：输入框逐个回车建

### 标签上限 10 个 —— 而且平台会**自动塞标签**

实测被塞过：`V2`（文件名）、`生活记录`、`记录`、`日语现场`、`音乐现场`、`LIVE`

**这些会占掉 10 个名额。必须删掉无关的，再补上目标标签。**

删除方式：`.label-item-v2-container` 里的 `svg.close`。

### AI 声明（创作声明）

下拉选项：

```
内容无需标注
含AI生成内容              ← 选这个
含虚构演绎内容
内容含营销信息
个人观点，仅供参考
内容为转载
内容是否添加内容授权声明（非必选）
内容为自制：未经作者允许，禁止转载
```

### 分区选择陷阱 ⚠️

**「人工智能」既是分区名，也是常见标签名。用文本匹配会点错。**

判定必须靠 **DOM 祖先链**：

```
✅ 分区下拉选项：  P.item-cont-main < DIV.drop-list-v2-item-cont < DIV.drop-list-v2-item
❌ 标签区          P.label-item-v2-content < DIV.label-item-v2-container < DIV.tag-pre-wrp
```

### 封面：两个独立面板

- **首页推荐封面（4:3）**
- **个人空间封面（16:9）**

**两个面板是分开激活的**，点错就会把图传进错的槽。详见 `gotchas.md`。

## 微信视频号

### 字段

- **短标题**（≤16，**禁中文逗号**）—— 本流程**默认不写**
- **视频描述**：`div.input-editor`（在 wujie shadow DOM 里）
- **位置**：默认设为「不显示位置」

### AI 声明（视频标注）

```
无需标注
含AI生成内容              ← 选这个
内容为虚构剧情，仅供娱乐
个人观点，仅供参考
内容包含营销广告
内容为自行拍摄
添加拍摄时间和地点
内容为转载
```

### ⚠️ 视频标注不会被「保存草稿」保存

实测两次：设置 → 保存草稿 → 重新打开 → **丢回「选择视频标注」**。
（同一轮里短标题的清空**能**保存住。）

**所以视频标注必须作为最后一步设置，设完不再保存草稿，直接交给人工复核发布。**

### 封面 ⚠️ 2026-09-29 实测已改版

**现在只有一个 3:4 槽**，页面上写的是「**个人主页和分享卡片(3:4)**」——**不再是** 个人主页 3:4 + 分享 4:3 两个槽。

后果：

- **横屏 4:3 封面在视频号没有槽可放**，别以为漏传了；
- 验收看 `.vertical-cover-wrap img` 的 src 是不是 `finder.video.qq.com` 的 CDN URL（本地 blob 不算被接受）；
- 编辑器入口：`.edit-btn` → 弹层里 `button "上传封面"` → 传完**必须重新快照**取「确认」的 ref（点上传后 refs 会整体位移，沿用旧 ref 会点空）。
