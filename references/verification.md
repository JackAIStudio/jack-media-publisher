# 发布草稿验收

每次在本条作品的编辑器、上传卡或封面主卡内回读结果。修改前记下已有的字段值、话题或封面来源，修改后核对同一处。已经符合要求的项目可直接验收。

## 视频上传

微信视频号的选文件、本地预览和平台上传各有独立信号。按当前能证实的阶段记录。

| 微信视频号状态 | 本条视频的证据 | 可以做什么 |
|---|---|---|
| 已选择文件 | 视频上传卡对应的 `input.files[0]` 与所选文件的名称、字节数相符 | 记录已选，观察原编辑页 |
| 本地待读取 | 文件已选，后台编辑页 `document.visibilityState === 'hidden'`，对应视频 `readyState === 0` 且 `duration` 为空或 `NaN` | 保留原素材和页面，等预览读出元数据 |
| 可预览 | 同一视频的 metadata 已可读，`readyState >= 1`，`duration` 为有限正数 | 核对时长及 `videoWidth`、`videoHeight`。本地 `blob:` 也能提供这些数据 |
| 平台上传或转码中 | 该卡片有上传百分比、「取消上传」「转码中」或「处理中」等提示，或字段仍提示等待上传 | 等当前处理结束。封面卡可能提前出现 |
| 平台上传完成，可编辑 | 平台明确显示本条视频上传成功，或先前锁定的字段已解锁。本条已无上传、转码或失败提示，所需字段可编辑 | 填描述、核对封面入口并继续草稿流程 |

实测同一份 MOV 在可见预览里先读出了时长，原编辑页随后也读到了元数据。遇到这组信号，沿用原素材，在原编辑页继续核对平台状态。其他平台同样看当前上传区的完成信号，例如 B站的「上传完成」。上传工具返回文件名或页面出现 `video` 元素，只能记录相应的本地状态。

## 字段和话题

- 标题和短标题回读文本框的 `value`，描述和简介回读其编辑器内容。微信视频号核对视频描述里的原标题和话题，以及短标题是否按本次要求留空或填写。
- 话题只在目标编辑器或标签区内按名称核对。小红书读话题实体 `data-topic` 中的 `name`，抖音读选中的 mention，B站读标签，微信视频号核对描述中的 `#话题` 及其高亮。逐项确认请求的话题，检查误选项、重复项和残留查询词。推荐区和手机预览不参与计数。见[话题控件](selectors.md#话题)。
- 原创与 AI 标注分别验收。原创按本条权属回读勾选状态，页面没有该字段就记「无此项」。按成片判断本条 AI 标注，收起候选列表后回读内容字段的选中值或约定的留空占位。B站有自制授权时，一并复核两项的最终状态。见[内容声明](platforms.md#内容声明)。
- **未关联活动硬核验**：除非用户明确提起要求参加某个具体活动，否则验收时必须逐平台确认未关联任何活动——小红书「关联活动」区无「取消关联」按钮（因话题自动勾上的须先点「取消关联」解除）、抖音无已挂载活动/任务、B站无已选中的「参与话题 / 参与活动」、微信视频号「活动」保持未选。见[禁止关联活动](platforms.md#禁止关联活动全平台红线)。
- B站在分区字段里回读最终选中值，对照草稿主旨与本次下拉的实际分区。交付时写明所选分区。

## 封面

1. 按主页面可见的编辑入口列出卡片名称与比例，再对照用户实际提供的源图。小红书核对是否匹配成片显示方向（竖屏 3:4 / 横屏 4:3）或指定来图。微信视频号等成片处理完成后，竖屏核对共用的 3:4 主卡，横屏分别核对个人主页 3:4 与分享 4:3。方形片或带旋转信息的成片也以实际入口为准。弹窗示意与手机预览不另计槽。见[微信视频号封面](platforms.md#视频号封面)。
2. 在目标卡片选图后，先核对编辑区构图，确认后再看该主卡实际绑定并显示的图。用源图的文字、主体位置或裁切等可辨特征核对来源。若编辑区已显示来图而主卡仍是视频首帧，记录该槽待核实。
3. 每个槽据实报告。部分来图时可以分别写「主页 3:4｜用户来图已核对」「分享 4:3｜未提供，保留平台默认」。若槽位为空则写空，来源不明则写待核实。

| 平台 | 确认后的观察位置及辅助回执 |
|---|---|
| 小红书 | 主封面卡已加载的平台图片（如 `ros-preview.xhscdn.com` 或 `sns-creator-preview.xhscdn.com`）。出现「封面效果评估通过」可另记质检通过 |
| 抖音 | 重开草稿后分别核对横、竖主卡内的图片。「横/竖双封面缺失」警告消失只说明平台检测到槽里有图 |
| B站 | 核对主表单中首页推荐与个人空间各自绑定的平台图片（如 `biliimg.com`），再对照各自的源图 |
| 微信视频号 | 回到刚才点「编辑」的主卡，核对平台回显的图片（如 `finder.video.qq.com`）是否对应来图 |

平台可为同一图片复用 CDN URL，也可更新同一图片的签名。URL 的变化或异同都不能单独判定来源。核验时可在页内查看图片绑定，报告只列卡片、比例、来源与结果，私有签名 URL 不写入日志或交付内容。

## 草稿复查与交接

微信视频号先保存草稿。收到「已保存」后，在独立标签页打开草稿列表，核对对应条目的标题（或描述摘要）和成片时长。列表摘要不足时，从列表复开该稿核对描述中的原标题与话题。同名稿结合保存时间与封面辨认。能复查的草稿与当前编辑页的标注分开报告。

草稿复查完，在要交给用户的编辑页最后按本条成片设置视频标注。核对按钮文本与本条判定值一致，留在这一页，**设完不再保存**。B站也可由草稿列表的标题、保存时间及对应内容复查落盘结果。

## 续做与最终状态

续做时，`already_ready` 表示本条已有完成证据，`resume_existing` 表示沿用当前选择或正在处理的上传，`injected` 仅记录本轮已投递文件。先核对编辑页或草稿，避免重复上传。

逐平台交接已证实的上传阶段、字段、各封面槽和草稿复查结果。有缺项或提示时列明实际状态。已约定的项目核对完毕、页面无阻塞且最终按钮可用时，可报告「待人工复核发布」，由用户点击最终发布。
